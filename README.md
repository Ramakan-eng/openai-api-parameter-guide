==> OpenAI API Parameter Guide

A concise practical guide explaining how to control LLM responses using OpenAI ChatCompletion parameters.

This repository documents key parameters that influence response creativity, length, diversity, repetition, and cost.

📘 Covered Parameters

Message Roles – system, user, assistant

temperature – Controls randomness

max_tokens – Limits response length

top_p – Nucleus sampling for response diversity

n – Generate multiple completions

stop – Custom stopping sequences

frequency_penalty – Reduces repetition

presence_penalty – Encourages topic variation

Each parameter includes explanation + Python example.

==> Why This Matters

Understanding these controls is essential for:

Building production-ready AI applications

Optimizing token usage and cost

Controlling hallucination and repetition

Designing structured LLM outputs
